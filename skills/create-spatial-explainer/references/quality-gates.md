# Quality gates

Treat these as separate evidence classes:

1. **Explanation:** correct causal relationships, explicit simplifications, no unsupported fidelity claims. Check representative parameter endpoints and identities.
2. **Time:** elapsed time agrees across model, progress and text; pause/seek/replay/completion and hidden-tab suspension work.
3. **Interaction:** controls change visible geometry and computed outputs. Hidden configuration cannot receive focus; pause/exit remains reachable. Selection and reset behave predictably.
4. **Visual:** actual subject prominent, legible depth and materials, no overlapping labels, readable contrast, restrained motivated motion. Check initial, transformation and final states.
5. **Access:** descriptive labels, keyboard controls, reduced motion, narrow/tall viewports and usable fallback.
6. **Performance:** only visible scenes animate, avoid creating geometry every frame, release resources, record actual measured hardware. Do not invent a frame rate or Lighthouse score.
7. **Delivery:** local dependencies, license notes, reproducible commands and accurate deployment status.

For a new mechanism, sample a full cycle and check constraints. For event models, verify work conservation and bounded queues. For optics, verify the lens equation. Tests that merely mirror implementation are not proof of correctness; test independent invariants.

Use a completion record with: check, observed result, environment, evidence, remaining limit. A failure in a hard requirement cannot be averaged away by a visual score.


## Quantitative teaching exhibits

- Choose geometry from the relationship: indexed tables for lookup, aligned spans for segmentation, equal-scale coordinates for vectors, weighted links for information flow. Reuse the player and review method; do not force unrelated subjects into one wheel or machine.
- Keep one sampled state for computed values, geometry, timeline and the current explanation. Reserve measured callout height before fitting the diagram. Convert SVG anchors with its screen transform, including letterbox margins; compute connector starts from the newly placed bubble, not its previous position.
- Route annotation lines through empty corridors. Inspect every selectable object, including negative-coordinate and long-label cases, while paused and during configuration transitions; a line that reaches its target can still obscure other data.
- Hold a stable result after a causal motion. Offer a fixed-input or fixed-model counterfactual plus a short predict → operate → explain check. Explain the tempting wrong inference; do not reduce feedback to a correctness badge.
- Label authored teaching values, scripted events, coordinate semantics and absent model operations at the point of use. Distinguish a static token lookup from later contextual processing, and an identifier from a quantitative magnitude.
- Keep evidence classes explicit: numerical invariants, browser actions, controlled event simulation and real device observations are different. Record repaired visual failures. Do not claim that a visibilitychange test proves OS tab suspension, an iframe proves physical-phone behavior, or developer teaching review proves measured learning gains.
