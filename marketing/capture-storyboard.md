# 演示拍摄与发布素材

## 15 秒主视频

| 时间 | 画面 | 屏幕短字 |
| --- | --- | --- |
| 0–2 秒 | 完整仪表界面，手指/鼠标点播放 | 原理，能不能亲手看懂？ |
| 2–5 秒 | 两侧与底部配置缓动退场，主体突出 | 把注意力，还给主体 |
| 5–9 秒 | 行星齿轮转动，沿轴向拆解 | 转动、拆开、看清连接 |
| 9–12 秒 | 演示完成，配置回来；调节转速 | 输入四圈，输出一圈 |
| 12–15 秒 | 切到模板与 Skill 入口 | Explain3D by funAgent |

旁白：一张原理图，看过不一定看懂。我把它做成能拖动、能拆开、能改参数的三维讲解。十秒看懂大概，停下来自己探索。Explain3D，模板、提示词和 Skill 一起开源。

桌面以 16:9 录制，竖屏单独用手机布局录制，避免把宽画面缩成难以辨认的小模型。字幕少而大；用实际演示速度，不剪出不存在的功能。保留无旁白、无音乐的原始版本。音乐仅用自有或已授权素材。

## 小红书六张图

1. 封面：真实拆解画面；标题“这个齿轮，拆开才懂”。
2. 完整初始界面：指出能拖动、能调节、能播放。
3. 演示中：两侧配置退场，主体突出。
4. 关系图：输入4 / 输出1；来自当前模型的明确参数。
5. 其他模板拼图：透镜、智能戒指、Attention、流水线，使用实际场景图。
6. 使用路径：体验模板 → 复制提示词 → 在 Agent 中创建 → 检查后分享。附官网与仓库名。

## 还应准备的内容

- 一段完整、无剪辑的演示，证明播放、暂停、拖动与恢复确实工作。
- 一次新场景复现过程，记录输入、修改和测试，解释 Skill 的可迁移性。
- 手机实机 GPU 与触摸录屏；完成前不标为实测通过。
- 公开 FAQ：普通屏幕深度感、真正裸眼立体的区别；支持平台、运行条件和简化边界。
- Issue 模板：收集“最想看懂的原理”，把真实需求变成后续模板。
- 发布后记录：体验入口点击、提示词复制、仓库访问与复现反馈；没有埋点时不要编造转化率。

素材可以先随仓库发布。社交账号的实际发帖、投放与社群发送另行执行。
