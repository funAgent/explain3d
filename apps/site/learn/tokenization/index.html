A SMALL BPE TOKENIZER

先有规则，再处理输入。

本页实现一个字符级 BPE 教学分词器。三条已确定的合并规则按优先顺序应用：u + g → ug；u + n → un；h + ug → hug。没有匹配的相邻片段时，该规则不产生变化。

规则顺序参考 Hugging Face 的小型 BPE 教学示例。原示例通过语料频率学习规则，本页仅演示已有规则的应用，不演示训练。滑块切换的是教学分词器的规则版本，不表示真实模型每次输入都重新训练。

ID 0…9：b, g, h, n, p, s, u, ug, un, hug

本页只接受五个预设英文词，不处理空格、中文、特殊 Token、Unicode 归一化或未知字符。真实 tokenizer 可能使用字节级 BPE、WordPiece、Unigram 等方法。这里的分词结果与 ID 不能当作 ChatGPT、Claude 或其他模型的真实结果。
